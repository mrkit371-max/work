# 🏋️ Календарь тренировок (PWA)

Мобильное мини-приложение: планирование тренировок по дням, каталог упражнений с техникой и картой мышц, отметки выполнения и статистика.

## Возможности

- **📅 Календарь** — месяц с цветными метками (зелёный — выполнено, оранжевый — запланировано). Клик по дню → список тренировок, добавление/редактирование/удаление, отметка выполнения.
- **📝 Редактор тренировки** — название, тип (силовая / кардио / растяжка), перенос на другой день (кнопки «сдвинуть»), заметки.
- **💪 Упражнения и подходы** — к каждому упражнению добавляйте подходы «вес / повторы» (или время для кардио/планки) и отмечайте выполненные.
- **🏗 Справочник упражнений** — 24 упражнения по категориям с подсказками: старт, дыхание, темп, типичная ошибка. Плюс свои упражнения.
- **🗺 Визуализация мышц** — SVG-схема «вид спереди / вид сзади» подсвечивает целевые и вспомогательные мышцы выбранного упражнения. Есть и карта за месяц: какие мышцы активнее всего работали.
- **📈 Прогресс** — статистика за месяц и 12 недель, недельный объём, график рекордов веса по упражнению.
- **⚙️ Профиль** — имя, рост, вес, недельная цель, тёмная тема, уведомления, экспорт/импорт JSON, полная очистка данных.

Все данные хранятся только в браузере (localStorage) — никуда не отправляются.

## Запуск

Нужен любой локальный сервер (для PWA нужен `http(s)`), например:

```bash
cd public
python -m http.server 8877
```

Затем откройте `http://127.0.0.1:8877` в Chrome на телефоне/компьютере.

## Установка на телефон (Android/iOS)

1. Откройте адрес приложения в Chrome (Android) или Safari (iOS).
2. Android: меню ⋮ → «Установить приложение». iOS: «Поделиться» → «На экран “Домой”».
3. Приложение работает офлайн (сервис-воркер кэширует файлы).

## Структура

```
public/
  index.html     — разметка
  styles.css     — оформление (тёмная/светлая тема через CSS-переменные)
  app.js         — вся логика: состояние, календарь, редактор, каталог, графики
  sw.js          — сервис-воркер (офлайн-кэш)
  manifest.json  — манифест PWA
  icons/         — иконки (генерируются скриптом)
scripts/
  make-icons.ps1 — генерация иконок (PowerShell + GDI+)
```

## Данные

- Хранилище: ключи `wt_workouts_v1`, `wt_custom_ex_v1`, `wt_profile_v1`, `wt_dark`.
- Резервная копия: «Профиль → Экспорт (JSON)», восстановление — «Импорт (JSON)».
